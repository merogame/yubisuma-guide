# 指スマガイド

[ガイドを開く](https://merogame.github.io/yubisuma-guide/)

二人対戦の指スマで、均衡戦略から抽選した行動を案内するガイドです。親は指を上げず、子が上げる本数だけを予想するルールを使います。

## 使い方

1. 「先手」「後手」を選びます。先手が最初の親になります。
2. 上部に相手と自分の残り本数、中央に推奨行動を表示します。「親・指定」のときは表示された数字を指定し、「子・上げる」のときは表示された本数を上げます。
3. 下部の数字で相手の行動を入力します。相手が子なら上げた本数、相手が親なら指定した数字です。
4. 相手の行動を入力すると、残り本数を更新し、すぐに親子を交代して次の推奨行動を表示します。
5. 先に残り本数が0になった方が勝ちです。「勝ち」「負け」の表示中は下部のボタンが無効になります。中央をタップすると、先手・後手の選択に戻ります。

右上の「↶」で直前の入力を戻せます。推奨行動も、その回に抽選したものに戻ります。過去128回まで戻せます。履歴がないときは、先手・後手の選択に戻ります。

## ルール

- 両者とも残り2本から始めます。
- 親の上げる本数は、双方とも常に0本です。
- 子は0本から自分の残り本数まで上げられます。親はその範囲の数字を指定します。
- 数字と上げた本数が一致すると、親の残り本数を1本減らします。外れたときは減りません。
- 当たり・はずれにかかわらず、親子は毎回交代します。
- 先に残り本数が0になった人が勝ちです。

## 均衡戦略

親も子も、子が出せる本数から均等に抽選します。子の残りが2本なら0・1・2を各1/3、1本なら0・1を各1/2で選びます。

一致した場合の続行先は、どの数字で一致しても同じです。外れた場合の続行先も同じです。均等に選ぶと、相手がどの数字を選んでも一致する確率が同じになるため、この戦略は対戦全体の均衡になります。双方が均衡に従う場合、開始時の勝率は先手55%、後手45%です。

抽選には `crypto.getRandomValues` を使い、余りの偏りが出る値を除きます。推奨行動は同じ回の間は固定されます。均衡をその場で計算する処理や、戦略表の読み込みは不要です。

## 構成

- `index.html`：ガイドのページ。
- `指スマガイド.html`：保存用。`index.html` と同じ内容です。
- `README.md`：この説明。
- `.nojekyll`：静的ファイルをそのまま配信する設定。
- `tools/verify-strategy.mjs`：ルールと均衡戦略の検証。
- `tools/verification.json`：検証結果。

HTMLは約7.5KBです。保存すれば直接ブラウザで開いて使えます。外部ライブラリ、画像、外部フォント、サーバー処理は使いません。対戦内容を保存・送信する処理もありません。

画面は一画面に収め、ページ内のピンチ、ダブルタップ、ホイール、拡大ショートカットを抑止しています。ブラウザ自身の設定やアクセシビリティ機能による拡大は、ページから完全には禁止できません。

検証はNode.jsで `node tools/verify-strategy.mjs` を実行すると再現できます。全8局面・52通りの行動の組み合わせ、合法な本数の範囲、均等な抽選を確認します。別の勝率計算でも、均衡から相手の行動だけを変えた場合に勝率が変わらないことと、開始時の先手55%・後手45%を検証します。
